# Стратегия: путь к цели

## 0. Как это читать

Мета для человека. В промпт не уходит.

## 1. Скелет: семь фаз

Таблица фаз: длительность, задача, темп веса, вход и выход по составу тела.

## 2. Ф0 — возврат (недели 1–4)

Текущий этап: разгон объёма по неделям, целевые веса возврата по каждому
тренажёру, критерии выхода (гейт).

## 4. Тренировочные дни

Сплит поимённо по id каталога, недельный объём по группам, микроцикл,
оценка длительности сессии.

## 5. Прогрессия

Правило шага веса, что делать при застое, контрольные веса по месяцам.

## 6. Пробел каталога и зачем в плане ноги

Чего каталог не строит и почему группы, не входящие в эстетическую цель,
всё равно получают объём.

## 9. Если выпала неделя

Как программа деградирует при пропуске: одна неделя, две, три и больше.
