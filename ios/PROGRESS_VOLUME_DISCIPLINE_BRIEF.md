# Задача для Claude Design: «Объём» и «Дисциплина» на экране Прогресс (iOS)

## Что нужно
Спроектировать **два новых блока для экрана «Прогресс»** (`screens/progress.jsx`),
в одном языке с тем, что там уже есть (`RingMain` — liquid-glass кольца «Неделя · план»,
и `ExerciseProgressRow` — стеклянные строки со спарклайном):

1. **Объём по группам** — сколько рабочих подходов набрано по каждой мышечной группе
   за неделю относительно целевого диапазона тренера.
2. **Дисциплина** — насколько выполняется план тренера (факт vs план).

Данные **реальные и уже считаются на устройстве** — это не макет ради макета, блоки сразу
поедут в прод. Нужны аккуратные макеты обоих блоков **в контексте экрана** (между `RingMain`
и секцией «Упражнения») и во всех состояниях (см. ниже).

## Контекст / дизайн-система (уже в проекте)
- iOS, **SwiftUI**, всё на **JetBrains Mono**, язык — русский. Эстетика — liquid-glass
  (`styles.css`: `.liquid-glass`, `.glass`, `.chip`; типографика `t-display`, `t-num`,
  `t-label`, `t-label-lg`). Палитра: `--ink/2/3/4/5`, `--accent #FF4D1F`, сигналы
  `--ok #1F9D6B`, `--warn #D89324`, `--bad #DC4848`, бумага `--paper`.
- Экран «Прогресс» открывается тапом по плашке статистики на «Истории». Сверху: `TopBar`
  «Прогресс», переключатель периода **7D / 30D / All** (сегментед), `RingMain`, затем
  заголовок «Упражнения» + список `ExerciseProgressRow`.
- Новые блоки встают **между `RingMain` и «Упражнения»**, отступы как у соседей (gap 12–14).

> ВАЖНО про пересечение: `RingMain` сейчас показывает «Неделя · план» как кольца. Наша
> «Дисциплина» — тоже про выполнение плана. Тебе решать, как примирить: например, сделать
> центр/смысл `RingMain` именно процентом дисциплины, а «Объём» дать отдельным блоком; либо
> оставить `RingMain` как есть и аккуратно добавить два компактных блока. Главное — не должно
> быть двух разных чисел «% плана», противоречащих друг другу.

## Блок 1 — «Объём по группам» (окно: последние 7 дней)
Семь мышечных групп, для каждой: набрано подходов, целевой диапазон (min–max), статус.
Счёт ведётся по основной мышце упражнения. Целевые диапазоны (ориентиры тренера):

| Группа | Цель (подходов/нед) |
|---|---|
| Грудь | 10–16 |
| Спина | 10–16 |
| Квадрицепс/ягод. | 10–16 |
| Дельты | 6–12 |
| Бицепс | 4–8 |
| Трицепс | 4–8 |
| Бицепс бедра | 5–10 |

Статусы (цветовой код): **недобор** (< min) — нейтрально-приглушённый; **в диапазоне**
(min…max) — `--ok`; **перебор** (> max) — `--warn`. Желательно показать, где проходит
нижняя граница «уже достаточно».

**Реальный пример (рисуй на нём), 7 дней:**
- Грудь — 9 / 10–16 (недобор)
- Спина — 12 / 10–16 (в диапазоне)
- Квадрицепс/ягод. — 8 / 10–16 (недобор)
- Дельты — 7 / 6–12 (в диапазоне)
- Бицепс — 5 / 4–8 (в диапазоне)
- Трицепс — 6 / 4–8 (в диапазоне)
- Бицепс бедра — 2 / 5–10 (недобор, хронически отстаёт)

Идея визуала на твоё усмотрение: горизонтальные мини-бары с засечкой целевого минимума,
радиальные мини-кольца сеткой, и т.п. — лишь бы читалось с одного взгляда «где провал».

## Блок 2 — «Дисциплина» (период = выбранный 7D / 30D / All)
Сверка факт vs план по тренировкам, которые делались по совету тренера (в каждой такой
тренировке хранится снапшот плана). Показатели:
- **% выполнения плана** = выполненные подходы / запланированные (выполненные обрезаются
  планом, чтобы «лишние» подходы не задирали выше 100%);
- сколько тренировок шло по плану за период;
- сколько упражнений из плана **пропущено**;
- «X из Y запланированных подходов».

Цвет процента/полосы: ≥80% — `--ok`, 50–79% — `--warn`, <50% — `--bad`.

**Реальный пример (7D):** 82% · 3 трен. по плану · пропущено упр.: 2 · 31 из 38 подходов.

## Состояния для макетов
1. **Объём — норма**: смесь недобора/в-диапазоне (как в примере).
2. **Объём — пустая неделя**: все по нулям (после перерыва) — как показать ноль не уныло.
3. **Дисциплина — есть данные**: основной вид (пример выше).
4. **Дисциплина — низкая** (<50%, красный) и **высокая** (100%, без «пропущено»).
5. **Дисциплина — пусто**: ещё не было тренировок по плану за период — мягкая подсказка.

## Взаимодействия
- Переключатель **7D/30D/All** уже сверху: «Дисциплина» считается за выбранный период;
  «Объём» — всегда за 7 дней (недельные ориентиры так задуманы) — подпиши это явно
  («7 дней»), чтобы не путалось с периодом.
- Блоки можно делать некликабельными (просто сводка) либо «Объём» — тап разворачивает
  разбивку; на твоё усмотрение, но по умолчанию — статичные сводки.
